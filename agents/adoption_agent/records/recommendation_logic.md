# Permitted recommendation logic

| Recommendation | Meaning |
|---|---|
| Adopt | Routine use is supported for the specified application. |
| Bounded experiment | Limited operational learning with explicit authority and stop conditions. |
| Proof of concept | Establish feasibility before operating the service. |
| Monitor | Follow specific new evidence without commitment. |
| Defer | A named unresolved prerequisite blocks the proposed action. |
| Reject for the present | A demonstrated mismatch outweighs value for this use now. |

V2G grid export is distinct from V2B backup and ordinary managed charging. Utility permission and equipment compatibility cannot be inferred from EV ownership. In primary and contrast_1 those are hypothetical pilot assumptions, while warranty and commercial terms remain unknown. Appetite does not settle liability. Different preparation paths are legitimate even if both defer actual export. Contrast_2 tests missing external permission; ambiguous tests an unsupported revenue promise.

Strongest alternative: managed charging without grid export. Reversal condition: model-specific warranty treatment, accepted trial terms, and tested route-reserve protection. Operating staffing and sustained ownership require the organizational expert.
